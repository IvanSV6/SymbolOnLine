# SymbolOnLine

Настольное приложение распознаёт одну рукописную цифру от 0 до 9 по штрихам, записанным с холста. Алгоритм [$P](https://faculty.washington.edu/wobbrock/pubs/icmi-12.pdf#page=8) сравнивает рисунок с шаблонами в виде облаков точек.

## Запуск на Windows

В PowerShell из папки проекта с существующим `venv` выполните:

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

В PyCharm выберите интерпретатор `venv\Scripts\python.exe` и запустите `main.py`.

## Использование

1. Нарисуйте цифру мышью. Между штрихами можно отпускать левую кнопку.
2. Нажмите «Распознать». Для следующей цифры очистите холст.
3. Чтобы добавить свой шаблон, выберите правильную цифру, укажите автора и нажмите «Сохранить образец».

В Windows свои образцы хранятся в `%LOCALAPPDATA%\SymbolOnLine\samples.json`. Файл содержит метку, автора и исходные штрихи каждого образца. Двадцать встроенных демонстрационных шаблонов доступны при первом запуске.
