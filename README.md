# SymbolOnLine

Настольное приложение распознаёт по одному рукописному символу. Доступны 78 классов: цифры 0–9, латинские буквы A–Z и a–z и 16 знаков: `. , ; : ? ! ' " ( ) % - @ $ < >`. Свёрточные сети работают локально на CPU через NumPy. Обученные веса входят в поставку.

## Запуск на Windows

В PowerShell из папки проекта с существующим `venv` выполните

```powershell
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe main.py
```

В PyCharm выберите интерпретатор `venv\Scripts\python.exe` и запустите `main.py`.

## Использование

1. Нарисуйте символ мышью. Один щелчок ставит точку. Для запятой проведите короткий штрих с хвостиком, для двоеточия поставьте две точки.
2. Нажмите «Распознать». В режиме «Все символы» сеть выбирает из всего набора. Переключатель позволяет уточнить группу даже после распознавания, например при похожих начертаниях 0, O и o. Вероятности вычисляются внутри выбранной группы. В режиме «Цифры» используется прежняя модель.
3. Справа отображаются ответ и варианты с вероятностью выше 1 % в порядке убывания. Начните следующий символ, чтобы автоматически очистить рисунок и результат, или нажмите «Очистить».

## Качество распознавания

На 3 120 рисунках 20 контрольных авторов UJI автоматический режим дал 2 465 верных ответов (79,01 %). При выборе правильной группы — 2 888 (92,56 %).

| Группа | Рисунков | Верно автоматически | Верно с выбранной группой |
| --- | ---: | ---: | ---: |
| A–Z | 1 040 | 779 | 945 |
| a–z | 1 040 | 744 | 942 |
| Цифры | 400 | 343 | 386 |
| Знаки | 640 | 599 | 615 |

В автоматическом режиме верно распознаны 39 из 40 точек и 22 из 40 запятых. Ввод изолированного символа сохраняет неоднозначность форм, например `9/g`, `O/o/0` и запятой с апострофом.

## Воспроизведение

Исходные данные — E. Alpaydin и F. Alimoglu, *Pen-Based Recognition of Handwritten Digits*, UCI Machine Learning Repository, 1996. Использованы оригинальные траектории UNIPEN. При подготовке данных ось Y перевёрнута для соответствия координатам холста, каждый штрих растеризован отдельно. [Набор данных и атрибуция](https://doi.org/10.24432/C5MG6K) · [Лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Для воспроизведения обучения нужны CPU-версия PyTorch и утилита `gzip` в PATH для распаковки файлов Unix compress. На Windows подойдёт `gzip.exe` из Git for Windows (каталог `usr\bin`). Обучение выполнено с Python 3.14 и PyTorch 2.15.0+cpu. Веса обучаются на авторах 1–25 из тренировочной части и встроенных начертаниях, с вариациями наклона, пропорций, положения и толщины линий. Записи авторов 26–30 используются для валидации.

```powershell
$archive = Join-Path $env:TEMP 'symbol-pendigits.zip'
curl.exe -fLsS 'https://archive.ics.uci.edu/static/public/81/pen+based+recognition+of+handwritten+digits.zip' -o $archive
.\venv\Scripts\python.exe -m pip install torch==2.15.0 --index-url https://download.pytorch.org/whl/cpu
.\venv\Scripts\python.exe -m training.train $archive
.\venv\Scripts\python.exe -m training.evaluate $archive
.\venv\Scripts\python.exe -m training.evaluate $archive --baseline
.\venv\Scripts\python.exe -m unittest discover -s tests -v
```

Команда `--baseline` использует исходный распознаватель из коммита `9acb4ab` в истории Git. Обе команды оценки выводят матрицу ошибок со строками по истинной цифре и столбцами по предсказанной.

### Латинские буквы и знаки

Для модели `symbols.npz` используются оригинальные траектории из UJI Pen Characters (Version 2), F. Prat, M. Castro, D. Llorens, A. Marzal и J. Vilar (2008). Из архива отбираются 78 классов ASCII. Координаты переводятся из единиц планшета в пиксели холста. Минимальный размер рамки нормализации — 60 пикселей, поэтому короткая запятая и отдельная точка сохраняют свой размер относительно буквы. [UCI Pen Characters](https://doi.org/10.24432/C5FG8S) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

При обучении используются 40 авторов UJI из части `trn`, дополнительные цифры из обучающей части Pendigits, встроенные начертания цифр и варианты печатной `i` с точкой-щелчком. Сеть обучается 48 эпох со случайными искажениями. В автоматическом режиме общая модель оценивает суммарную вероятность цифр, а `digits.npz` распределяет её между десятью цифрами. Выбор группы букв или знаков ограничивает варианты до вычисления softmax.

Для воспроизведения выполните после установки зависимостей обучения и загрузки Pendigits:

```powershell
$uji = Join-Path $env:TEMP 'uji-pen-characters-v2.zip'
curl.exe -fLsS 'https://archive.ics.uci.edu/static/public/177/uji+pen+characters+version+2.zip' -o $uji
.\venv\Scripts\python.exe -m training.train_symbols $archive $uji
.\venv\Scripts\python.exe -m training.evaluate $uji --uji
```
